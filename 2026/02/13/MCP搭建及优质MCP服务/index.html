MCP搭建及优质MCP服务

作者: Elara
发表于2026-02-13
更新于2026-03-23
工具

在编写代码时经常要看本地的日志文件，或者读取数据库里的最新数据，只能手动复制粘贴，不仅繁琐，而且一旦数据更新，又得重来一遍

MCP（Model Context Protocol，模型上下文协议）正是为了解决这一痛点而生的。为AI模型提供一个开放、通用且有共识的协议标准。可以把MCP想象成AI世界的USB，让各种设备轻松互联，MCP也为AI模型连接不同数据源和工具提供了标准化方式。

没有MCP协议时，不同的AI大模型调用工具的标准各不相同，开发者需要为每个工具编写定制化的集成代码。有了MCP之后，所有大模型都通过这个统一协议进行工具调用，减少代码编写量。

一、MCP核心概念解析

1.1 MCP架构组成

一个完整的MCP系统包含三个核心组件：

  • MCP Client：如Claude、Cursor、CherryStudio等支持MCP的AI应用，负责发起各种AI能力请求
  • MCP协议：连接Client和Server，所有请求和响应都通过协议标准化传递
  • MCP Server：每个Server对接不同的数据源或服务，如本地数据库、文件系统、GitHub API等）

1.2 MCP传输方式

MCP支持多种传输协议，最常见的是：

传输方式 适用场景 特点
Stdio 本地集成、命令行工具 通过标准输入/输出流通信，适合本地进程间通信
SSE（Server-Sent Events） 远程服务、云端部署 支持HTTP流式传输，适合跨网络调用

3.1 开发工具类

GitHub MCP Server

官方地址：https://github.com/github/github-mcp-server
GitHub MCP Server让AI能够直接与GitHub仓库交互，是开发者最常用的MCP工具之一。

核心能力：

  • 浏览、查询和理解代码仓库
  • 创建和管理Issue、Pull Request
  • 监控GitHub Actions工作流
  • 审查安全警报和分析代码模式

Context7

官方地址：https://context7.com
Context7是一个轻量级的MCP服务器，专门为代码库优化，支持访问数百个开源库的最新文档。

核心能力：

  • 访问React、Tailwind、Next.js等开源库的最新文档
  • 避免模型使用过时的代码示例和幻觉API
  • 可自动在代码相关问题上被调用

Apifox MCP Server

官方地址：https://docs.apifox.com/apifox-mcp-server
Apifox MCP Server将API文档提供给AI工具，让AI能够根据接口文档自动生成代码。

核心能力：

  • 连接到Apifox项目内的API文档
  • 访问公开发布的API文档
  • 支持OpenAPI/Swagger文档
  • 根据API文档自动生成MVC代码

配置要求：Node.js版本≥18

3.2 设计协作类

Figma MCP

获取方式：在Figma桌面应用中开启

Figma MCP让AI能够访问结构化的设计上下文，是设计转代码工作流的利器。

核心能力：

  • 访问组件层级、设计令牌、变体信息
  • 支持自然语言编辑（如“把这个按钮居中”）
  • 布局感知重构（应用Auto Layout、修复间距）
  • 设计到代码同步

开启方式：

  1. 打开Figma桌面应用（最新版本）
  2. 左上角菜单 → Preferences
  3. 选择“Enable Dev Mode MCP Server”

四、MCP进阶：安全部署

4.1 权限控制原则

在生产环境中使用MCP时，遵循最小权限原则：

  • 只读优先：优先使用只读操作，确认需要时再开启写入
  • 严格范围：每个工具使用严格的作用域限制
  • 人工确认：对于破坏性操作，增加人工确认步骤
